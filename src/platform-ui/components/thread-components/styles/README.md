# Thread component styles

This directory owns the ordered CSS bundle mounted by thread and Runner
surfaces.

- `thread-component-css.ts` is generated by
  `scripts/runner-chat-assets.mjs`; never edit it manually.
- `thread-component-styles.ts` mounts the current generated or development-HMR
  bundle.
- The editable source order is defined once in
  `scripts/runner-chat-style-sources.mjs`.

The former `src/react/runner-chat-css.ts` and
`src/react/runner-chat-styles.ts` entries are compatibility facades.
