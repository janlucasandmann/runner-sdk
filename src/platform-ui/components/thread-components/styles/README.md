# Thread component styles

## Purpose

This directory owns the ordered CSS bundle mounted by thread and Runner
surfaces.

- `thread-component-css.ts` is generated by
  `scripts/runner-chat-assets.mjs`; never edit it manually.
- `thread-component-styles.ts` mounts the current generated or development-HMR
  bundle.
- The editable source order is defined once in
  `scripts/runner-chat-style-sources.mjs`.

The former `src/react/runner-chat-css.ts` and
`src/react/runner-chat-styles.ts` entries are compatibility facades.

## Working in this directory

Keep changes inside this directory's stated ownership boundary and use the parent's public entry point instead of importing sibling internals. Update this guide when responsibilities, entry points, or verification commands change. Place focused tests beside the behavior they protect and promote reusable, domain-neutral presentation to `src/platform-ui`.

## Verification

Run the narrowest relevant checks from the repository root:

```bash
npm run check:static
```

Escalate to `npm run check` before merging changes that affect shared contracts,
build output, or application composition.
